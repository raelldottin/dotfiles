## About

This repository is the declarative configuration for my macOS and Linux
workstations. The primary path is now Nix: Home Manager owns user packages and
dotfiles, nix-darwin owns macOS integration, and nix-homebrew keeps Homebrew as
the compatibility layer for GUI casks.

The previous shell/Python installer is retained temporarily as a rollback path
while the Nix configuration is validated on the real workstation.

## Architecture

| Layer | Responsibility |
| --- | --- |
| Home Manager | zsh, tmux, Neovim files, user packages, home-directory state |
| nix-darwin | Apple Silicon macOS system integration |
| nix-homebrew | existing Homebrew installation and GUI casks |
| flake.lock | pinned revisions for reproducible rebuilds |

## macOS Quick Start

From this repository on the Apple Silicon Mac:

```bash
nix flake check
sudo nix run nix-darwin/nix-darwin-26.05#darwin-rebuild -- \
  switch --flake .#macbook
```

After bootstrap:

```bash
nix flake update
sudo darwin-rebuild switch --flake .#macbook
```

Home Manager backs up conflicting files using the `.hm-backup` suffix during
the first nix-darwin activation.

## Linux Quick Start

x86_64:

```bash
nix run home-manager/release-26.05 -- \
  switch -b hm-backup --flake .#linux-x86_64
```

aarch64:

```bash
nix run home-manager/release-26.05 -- \
  switch -b hm-backup --flake .#linux-aarch64
```

## What Nix Manages

- `~/.zshrc` through Home Manager, including Oh My Zsh, autosuggestions,
  fast syntax highlighting, and Powerlevel10k.
- `~/.tmux.conf` as a compatibility shim plus the generated XDG tmux config.
- tmux plugins without TPM cloning.
- `~/.config/nvim/**` from the existing Neovim source tree.
- `~/.pylintrc`.
- core CLI and development packages from nixpkgs.
- selected macOS GUI casks through the nix-darwin Homebrew module.

## Migration Safety

The first pass intentionally does **not** remove unlisted Homebrew formulae or
delete the legacy installer. This keeps the migration reversible while the Nix
activation is validated on the actual Mac.

See [Nix Migration](docs/NIX.md) for the ownership map, rollout sequence, and
cleanup plan.
